AWP is a specification, not a platform. Any runtime may implement it.

## Platforms which support AWP

| Implementation | Status |
| -------------- | ------ |
| - | No implementation has published a conformance statement yet. |

No implementation is listed yet. This list changes only when a project states its support publicly.

Implementations that use their own extension fields can list their prefix in the informative [extension prefix list](https://github.com/agenticworkflowprotocol/agenticworkflowprotocol.org/blob/main/docs/registry/extension-prefixes.md).

## Call for implementations

AWP is not tied to any runtime. If you build a runtime, validator or tool that implements AWP, open an issue or pull request in the [repository](https://github.com/agenticworkflowprotocol/agenticworkflowprotocol.org) to be listed. Listing requires a public statement of the supported conformance profiles.
