# AWP brand assets

Logo files of the Agentic Workflow Protocol, served at `https://agenticworkflowprotocol.org/brand/`.

| File | Use |
| --- | --- |
| `awp-icon-{light,dark}.svg`, `.png` | Icon without wordmark (square, transparent) |
| `awp-wordmark-horizontal-{light,dark}.svg`, `.png` | Icon with "AWP – Agentic Workflow Protocol" side by side (headers, READMEs) |
| `awp-wordmark-stacked-{light,dark}.svg`, `.png` | Icon above the wordmark (title slides, posters) |
| `awp-open-graph-{light,dark}.svg`, `.png` | 1200 × 630 social preview |
| `favicon-{light,dark}.svg`, `-16.png`, `-32.png` | Browser icons |

`light` is for white or light backgrounds (dark letters), `dark` for black or dark backgrounds
(white letters). Prefer SVG; PNG is for places that cannot show SVG.

You may use the logo to refer to AWP, for example next to "supports AWP manifests" in
documentation. Do not change it, and do not use it in a way that suggests the AWP project endorses,
certifies or has reviewed a product: conformance is stated only as described in the
[conformance rules](https://github.com/agenticworkflowprotocol/agenticworkflowprotocol.org/blob/main/docs/aep-process.md#7-conformance-mark-proposal).
